cd c:\Users\nares\Downloads\backend\local_ai_service
.\run_setup.bat

This will:
  • Create Python virtual environment
  • Install dependencies (PyTorch, FastAPI, etc.)
  • Train Chatbot model (TF-IDF + Neural Network)
  • Train Disease Detection model (PyTorch CNN)
  • Start FastAPI server on http://localhost:8000

⏱️  First run takes 5-10 minutes (includes model training)

❓ TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Problem: "Python was not found"
  → Install Python 3.10+ and check "Add to PATH"

Problem: "venv not found"
  → Delete models/ folder, run run_setup.bat again

Problem: "Backend can't connect"
  → Verify: curl http://localhost:8000 works
  → Check firewall allows port 8000

Problem: "Models not trained"
  → Wait for run_setup.bat to complete
  → Check models/ folder has .pth and .pkl files

For more help → See CUSTOM_AI_SETUP.md
